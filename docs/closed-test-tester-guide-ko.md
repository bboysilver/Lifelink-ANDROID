1. 초대받은 Google 계정으로 [테스트 참여](https://play.google.com/apps/testing/com.bboysilver.lifelink)를 선택합니다.

3. 실제 문자 발송 가능한 SIM과 기본 문자 앱 발송을 확인하고, 동의한 보호자1명과 안전 설정·시험 문자 수신을 확인합니다. Wi-Fi 전용/데이터 전용 기기는 핵심 문자 시험에 적합하지 않습니다.
4. 테스트 참여를 취소하지 않고 추가14일 동안 평소처럼 휴대전화를 사용해 주세요. 앱은 백그라운드에서 동작하므로 계속 화면을 켜둘 필요가 없습니다.

## 부탁드리는 확인

- 평소처럼 걷거나 PIN/지문 잠금을 풀고 사용하는 동안 불필요한 경고 문자·소리·팝업이 오는지 알려주세요.
- 앱 글씨·버튼·권한 안내를 이해하기 쉬운지, 보호자가 경고 문자 이후 무엇을 해야 할지 이해했는지 알려주세요.
- 시험 문자/실제 경고의 앱 표시와 보호자 실제 수신은 각각 확인합니다. 발송/전달 표시는 사람의 안전 확인이 아닙니다.
- **실제6/12시간 무활동·재부팅·SIM 제거·절전/권한 차단·SOS 실제 전송 시험은 담당자와 합의한 별도 시험 단말에서만** 진행합니다. 실제 도움을 받아야 하는 이용자의 안전망을 끄고 시험하지 않습니다. SMS 비용과 긴급 상황 오해 가능성을 미리 설명합니다.
- 정상 생활 중에는 무활동 문자가 안 오는 것이 맞을 수 있습니다. 의도적으로 휴대전화를 사용하지 않은 시험과 구분해 주세요. 같은 사건에서 추가 문자를 주기적으로 반복하지 않는 기존 동작도 유지됩니다.
- 상태 점검을 위해 LifeLink를 여는 행위 자체가 활동으로 기록될 수 있습니다. 자동 감지는 `안심 > 작동 상태 점검`의 마지막 자동 활동 기록에서 별도로 확인해 주세요.
