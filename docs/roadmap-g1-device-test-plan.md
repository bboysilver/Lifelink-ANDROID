# G1 기기별 수동 시험 계획 — 전 항목 NOT RUN

2026-10-24. 이 계획은 실행 결과가 아닙니다. ADB에 연결된 기기는 없었습니다. 자동화/Robolectric 통과로 실제 SMS 전달·Doze·삼성 절전·TalkBack을 PASS 처리하지 않습니다.

## 사전 조건과 설치 경계

- 동의한 직원·자원봉사자 소유의 별도 시험 단말을 사용합니다. 이용자와 보호자에게 시험 시각·실제 SMS 요금·긴급 문자 오인 가능성을 설명하고 수신자를 확인합니다.
- Galaxy A24/PIN 등 보급형1대와 다른 Galaxy/Android 조합1~2대 이상을 권장합니다. 기종·API·실제 SMS 가능한 SIM·기본 문자 앱 발송·배터리 조건을 기록합니다. 데이터 전용 SIM이나 Wi-Fi 기기를 SMS 가능으로 추정하지 않습니다.
- 현재 G1 개발 산출물은 기준2.3.9(47)를 유지합니다. unsigned AAB는 Play 업로드/설치용이 아닙니다. debug APK를 기존 Play 설치본에 덮어쓰기 위해 기존 앱을 삭제하지 마세요. 서명이 다르면 별도 시험 단말만 사용합니다.
- 기존 데이터 보존의 실기기 검증은 별도 승인된 다음versionCode/동일 인증서 업데이트가 있어야 합니다. 이번 작업은 서명 Secret 입력·서명 CI·Play 업로드·main 병합을 하지 않습니다.
- 기존 정기 돌봄·전화·119·전문 관제와 대체하지 않습니다. 시험 중 문제가 나면 앱을 믿고 기다리지 말고 합의한 기존 연락 절차를 사용합니다.

## 중단/후속 게이트

SMS 누락·설명되지 않는 중복, 정상 오표시, 데이터 손실, 개인정보 공유 누출, 점검 때문에 타이머/사건이 사라짐이 있으면 실증/공개 확대를 BLOCKED 처리하고 재현부터 기록합니다. SMS/FGS/건강 앱/Data safety 심사 결과는 별도 담당자가 실제 Console/이메일로 확인해야 합니다. G2 합성 DEMO조차 별도 개발 승인이 필요하며 Family/Care 실데이터 연결·운영·결제는 NOT STARTED입니다.
