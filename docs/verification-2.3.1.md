# LifeLink 2.3.1 (39) — 온보딩 및 알림 회귀 검증

검증일: 2026-10-11. 공개 출시 승인이나 실기기 안전 성능 보장을 의미하지 않습니다.

## 수정 내용

- 권한을 전체 승인 여부 하나가 아니라 SMS·SIM·활동·알림의 개별 상태로 관리합니다. 권한 결과와 앱 복귀 시 다시 읽어 다른 권한이 미승인 상태여도 해당 스위치를 바로 갱신합니다.
- 기본/간편 홈에서 Family 요금제·무료 체험 안내를 제거했습니다. 구독 결제나 클라우드 기능을 새로 도입하지 않습니다.
- 필수 포그라운드 알림은 무음·낮은 중요도로 유지하며, 매분 남은 시간을 갱신하던 알림을 정적인 실행 상태로 바꿨습니다. 홈의 타이머와 활동 감지 주기는 그대로입니다.
- 발송 요청/재시도 진행은 동작 기록에서 확인합니다. 성공 콜백은 별도 무음 채널로, 최종 발송 미확인은 중요 안전 알림으로 표시합니다. 사건별 알림을 구분하여 같은 사건의 결과 갱신은 다시 울리지 않도록 했습니다.
- 무활동 사전 경고는 한 주기당 한 번만 표시합니다. 유효 활동·직접 무사 확인·중지·설정 재시작 시 해당 경고만 제거하고 SOS/SMS 실패 알림은 보존합니다. 구 버전의 사전 경고도 제목을 확인하여 안전하게 정리합니다.
- 중단 알림과 SOS 포그라운드 알림의 ID 충돌을 제거했습니다. 서비스 오류를 별도로 중복 경고하던 서비스/감시 작업 경로도 같은 중단 사건으로 처리합니다.
- 매일 안부 확인은 기존 선택 설정을 유지합니다. 기본값은 꺼짐이며 자동 활동 응답을 유지합니다. 재시작 시 복원 알림은 무음으로, 사용 해제/시간 변경 시 기존 알림은 제거합니다. 홈에 무활동 설정과 별도인 선택 기능임을 안내합니다.

## 보존한 동작

자동 유효 활동 판정, 저장된 마감시각, 선택 SIM, 보호자 연락처, 시험 문자, SOS 5초 취소, 실제 발송/전달 콜백, 최대 3회 재시도, 데이터 마이그레이션은 유지합니다. SMS는 등록된 보호자 번호로만 보내며 사용자에게 별도로 SMS를 보내는 경로는 없습니다. 사용자의 번호가 연락처에 등록되었는지는 실제 기기에서 확인해야 합니다.

## 알림 정책 및 실제 기기 확인

Android 포그라운드 서비스에는 실행 중 알림이 필요하므로 이를 숨기지 않습니다. [Android 공식 안내](https://developer.android.com/develop/background-work/services/fgs). 무활동 사전 경고, 실제 발송 실패, 모니터링 중단, 사용자가 켠 매일 안부 요청은 필요한 경고로 유지합니다.

ADB 연결 기기/에뮬레이터가 없어 이번 버전의 실제 통신사 SMS·삼성 장기 절전·실제 진동/소리 결과는 검증하지 않았습니다. 자동 테스트를 실기기 성공률로 해석하지 않습니다.

1. 기존 설치를 삭제하지 않고 Play에서 업데이트하여 연락처·SIM·12시간 설정을 보존하는지 확인합니다.
2. 신규 설치에서 권한 스위치를 하나씩 승인하고, 특히 SMS 스위치가 이전 화면으로 이동하지 않아도 즉시 허용됨으로 바뀌는지 확인합니다.
3. 잠금 해제/정상 활동 후 타이머 갱신 및 기존 사전 경고 제거를 확인합니다. 기본 실행 알림은 무음이며 매분 새 경고가 생기지 않아야 합니다.
4. 정기 안부 확인이 필요 없다면 `매일 안부 확인 → 사용 안 함`을 선택합니다. 기본 무활동 문자와 SOS는 계속 유지됩니다.
5. 동의한 보호자에게 시험 문자/SOS/무활동 문자를 확인하고, 비행기 모드·SIM 변경·권한 해제 시 실패/중단 경고를 확인합니다. 실제 SMS가 사용자 폰에도 도착하면 수신 연락처에 사용자 번호가 포함되어 있는지 확인합니다.

GitHub 서명 CI와 Play 제출의 실제 결과는 별도 배포 기록에 남깁니다. 이 문서만으로 업로드 완료를 주장하지 않습니다.
