# R1 현장 파일럿 기술 검증 계획

작성: 2026-10-18. 대상: 2.3.5 (43) 로컬 MVP. 공개 출시·기관 실사용 승인 문서가 아니다.

## 범위와 사전 동의

동의한 직원·자원봉사자의 기기만 사용한다. 공식 방문·전화 돌봄과 기존 비상 연락체계를 대체하지 않는다. 실제 고령 대상자 적용은 기관의 책임·법적 근거·개인정보 검토·실증 승인이 완료된 뒤 별도 결정한다.

- 이용자와 보호자에게 시험 시각·실제 SMS 비용·긴급 문자 오인 가능성을 설명한다.
- 시험 수신자를 직접 확인한다. 전화번호·문자 내용·원시 로그를 공개 이슈/CI에 올리지 않는다.
- 모니터링·일일 안부·SOS는 기존 기능이다. 시험할 기능과 예상 수신 횟수를 먼저 합의한다.
- 실제 SIM 발송은 수동으로만 한다. 자동화 검사는 통신사 문자 전달이나 장시간 신뢰성을 증명하지 않는다.

## 기록 양식

임시 시험기기 코드 / 동의 확인 / 앱 버전 / Android API·기종 / 시험 조건 / 예정 마감 / 실제 점검·콜백 시각 / 수신자가 별도 확인한 수신 시각 / 기대 결과 / 실제 결과 / 조치 필요 여부. 외부 공유본에는 정확한 활동 이력·이름·전화·본문을 포함하지 않는다. 내부 시험자료도 접근·보관·폐기 책임자를 먼저 정한다.

## 기존 안전 기능 장시간 검사

1. Galaxy A24를 포함한 SMS 가능 보급형 + 실제 SIM, Android 7/주요 최신 버전을 구분한다. Wi-Fi 전용/데이터 SIM은 발송 성공을 가정하지 않는다.
2. 6시간 이상 화면 OFF/Doze와 삼성 수면 앱/배터리 제한 조건을 각각 기록한다. 마감→실제 점검→SENT→수신 시각을 따로 측정한다. 열기 직후 과거 사건 경고가 늦게 발송되는 현상은 계속 조사 대상이다.
3. 한 사건 처리 후 6·12시간 추가 무활동: 새 주기 SMS는 없어야 한다. 서비스 지속 여부는 별도로 확인한다. 새 문자가 없다는 사실은 사람 안전/서비스 실행 증거가 아니다.
4. 새 유효 활동 후 새 설정 시간이 시작되고, 이후 무활동이면 새 사건 경고가 한 번 발생해야 한다.
5. 비행기 모드/통신 불가→복구 시 기존 5분 간격·최대 3회 수신자별 재시도를 확인한다. 부분 성공 수신자에게 중복 전송하지 않는다.
6. 일일 안부의 유효 활동 자동 응답, 시간대 변경, 직접 응답을 검증한다. SOS는 5초 취소와 복구를 검증한다.
7. 재부팅·앱 업데이트·명시 중지·강제 종료·권한 철회 각각에서 오표시/데이터 손실을 확인한다.

앱을 직접 열거나 터치하면 기존 MainActivity의 활동 감지로 타이머가 갱신될 수 있다. 다른 사람이 점검한 것만으로 이용자 안전이 증명되지 않는다. 장기 무활동 실험 중 앱을 열어서 관찰하는 행위 자체가 시험 조건을 바꿀 수 있으므로 따로 기록한다.

## 중단 기준

SMS 누락/중복, 서비스 중단 정상 오표시, 개인정보 포함 공유, 업그레이드 손실, 공식 돌봄 대체 상황이 생기면 배포/실증을 중단하고 원인 분석한다. 자동화 통과만으로 이 항목을 완료 표시하지 않는다. 결과·환경·미실행을 구분해 `field-pilot-verification.md`와 별도 내부 실기기 기록에 남긴다.
