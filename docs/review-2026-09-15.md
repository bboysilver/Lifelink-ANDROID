# LifeLink 개발·정책·출시 검토

기준: 2.2.12 (33)에서 2.2.13 (34)으로 보완. 로컬 SIM 기반 Android 안전 보조 앱.

## 수정한 결함

- 서비스 초기화 실패 후 도착하는 시작 명령이 ERROR를 RUNNING으로 덮어쓰는 경로를 차단했다.
- 화면이 꺼져 CPU가 쉬는 동안 코루틴 검사만으로 마감시각을 확인하던 경로에 비정확 AlarmManager wakeup과 영속 작업을 추가했다. 정확한 알람 권한은 요청하지 않는다. 중지/활동 확인 이후 옛 알람은 무시한다.
- 기록 삭제가 안전 문자의 성공 상태까지 지워 다른 보호자 재시도 중 중복 전송을 허용하던 문제를 수정했다. 본문·연락처가 없는 중복 방지 상태는 90일 보관한다.
- 시간 초과 후 다음 시도 전에 도착한 성공 콜백을 반영한다. 동시에 저장되는 사건 상태가 SENT/DELIVERED에서 이전 상태로 돌아가지 않도록 했다.
- 시험 문자 콜백 누락은 2분 후 확인 실패로 종료하며 자동 재발송하지 않는다.
- 안부 확인에서 도움 요청/SOS 취소를 무사 확인으로 처리하지 않는다. 직접 '괜찮아요' 응답 전까지 안부 확인은 남는다.
- Android 6/7에서 지원되지 않는 알림 설정 화면을 호출하던 경로를 앱 상세 설정으로 연결했다.
- 초기 동의 전에 전체 개인정보처리방침을 열 수 있게 하고 SMS 전송 정보·요금을 설명한다. 입력 상태는 화면 재생성 후 복원한다.

## Google Play

검토 시 Console은 기존 2.2.12가 2026-09-10 게시됐으며 Policy status는 'No issues found', App content는 미완료 요구 없음으로 표시했다. 이것은 이번 변경이나 앞으로의 공개 출시 승인 보장이 아니다.

Data Safety는 기존 'No' 답변을 검토했다. 기기 밖으로 보내는 SMS도 [Google의 수집 정의](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)에 들어가므로 서버가 없다는 이유로 전부 제외하지 않는다. 문자에 포함되는 별칭(Name), 발신자·수신자·본문(SMS or MMS), 배터리(Diagnostics)를 기능 목적으로 선언한다. 사용자 지정/고지·동의에 따른 보호자 전달은 공유 예외를 적용한다. 별칭은 선택, 핵심 문자·배터리 전달은 필수이며 일시 처리로 표시하지 않는다. SMS 종단간 암호화를 주장하지 않는다. 계정은 없다. 보호자 기기로 전달된 SMS는 앱이 삭제할 수 없다는 점을 방침에 명시한다.

- SEND_SMS는 [물리적 안전·긴급 알림 예외](https://support.google.com/googleplay/android-developer/answer/10208820?hl=en) 심사 대상이다.
- 현재 health FGS와 ACTIVITY_RECOGNITION의 실제 활동 확인 용도를 [FGS 선언](https://support.google.com/googleplay/android-developer/answer/13392821)에 설명한다. 정책 우회용 서비스 타입/권한은 추가하지 않는다.
- 광고/AD_ID/위치/인터넷/결제 SDK는 없다. targetSdk 36과 minSdk 23을 유지한다.
- 개발자 검증 및 패키지 등록 상태는 Console에서 확인해야 한다. AAB 업로드와 별도다.

## iOS와 구독

iOS는 [사용자 확인이 있는 문자 작성 API](https://developer.apple.com/documentation/messageui/mfmessagecomposeviewcontroller)를 제공하며, [일반 백그라운드 실행](https://developer.apple.com/documentation/BackgroundTasks/choosing-background-strategies-for-your-app)의 시각을 보장하지 않는다. Android 자동 SIM 문자 기능의 단순 이식은 불가능하다. iOS 보호자 모드 → 서버 안부 마감 관리·SMS → 사용자 모드 순서로 개발한다. 별도 iOS 앱은 이번 릴리스에 포함하지 않는다.

구독은 Family 실제 서버·보호자 기능 검증 후 적용한다. 월 3,900원/연 39,000원은 가격 가설이며, 무료 안전 기능은 유지한다. [Play Billing 지원 버전](https://developer.android.com/google/play/billing/deprecation-faq), 서버 구매 검증·승인·갱신/환불 처리, 계정 삭제를 갖춘 뒤 청구한다. 현재 유료 서비스/매출 구현은 없다.

## 검증과 남은 출시 조건

자동 테스트·lint·debug 빌드 및 GitHub 서명 AAB 검증으로 코드 회귀를 확인한다. 실제 통신사 SMS를 자동 시험한 결과로 해석하지 않는다.

공개 출시 전 30가구 4주 실증에서 Doze/재부팅/권한 해제/SIM 변경/통신 단절/멀티파트 문자를 확인한다. 발송 성공률, 누락·중복, 오탐과 배터리 소모를 측정한다. 통신사 콜백이 유실된 경우 '정확히 한 번 전송'은 로컬 SMS만으로 보장할 수 없으며, OS 강제종료/전원 꺼짐도 감지할 수 없다. 이 제한을 보완하는 서버 상태 확인이 Family의 우선 개발 과제다.
