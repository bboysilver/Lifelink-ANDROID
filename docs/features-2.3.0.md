# LifeLink 2.3.0 (38) — 안전 보조 기능

공유 대화의 우선순위에 따라 외부 서버 없이 현재 제품에 적용 가능한 기능을 구현합니다. 기존 무활동·안부 미응답·SOS의 발송 조건, 자동 활동 응답, 콜백 처리와 재시도 정책은 유지합니다.

## 추가 기능

1. 홈의 **작동 상태 점검**: 실제 서비스 heartbeat, 마지막 감지 활동과 사유, 마지막 SMS 발송 확인 시각(시험 문자 포함), 센서 지원, 필수 권한·알림 채널, SMS 회선과 배터리 제한을 보여 줍니다. 오래되거나 미래 시각인 heartbeat, 시작 중·중단된 서비스, 누락 설정은 실행 확인으로 표시하지 않습니다. 배터리 설정은 사용자가 직접 여는 방식이며 앱이 제한을 자동 해제하지 않습니다.
2. **알림 문자 맥락**: 무활동 문자는 설정 시간과 마지막 감지 활동을, 매일 안부 문자는 별도 2시간 유예 사유와 안부 기준 시각을 표시합니다. 시간이 없으면 `기록 없음`으로 표시합니다. 문자 본문은 사건 생성 시 고정되어 재시도 중 활동·설정·시간대가 바뀌어도 바뀌지 않습니다. 긴 문자 요금은 통신사 요금제에 따라 달라질 수 있습니다.
3. **가족 안부 확인 기록**: `기록 > 가족 안부 확인 기록`에서 최근 발송 시도 사건 20건에 대해 `연락 중`, `직접 안부 확인함`, `도움 필요`를 수동 기록합니다. 확인창에서 기능의 범위를 설명합니다. 보호자의 원격 응답이나 SMS 열람 확인이 아니며, 기록만으로 SOS가 전송되지 않습니다. 사건의 문자 상태와 별도 저장되며 진행 중인 재시도를 취소하지 않습니다. 앱 화면을 직접 조작한 것은 기존 규칙에 따라 활동 신호로 처리될 수 있습니다.
4. **간편 홈**: 큰 무사 확인·SOS 버튼과 필수 상태만 중심으로 보여 줍니다. 선택을 재실행 후에도 보존하며 기존 시간·매일 안부·SMS 설정은 바뀌지 않습니다. 다시 끄면 시간 설정과 준비 중 구독 안내를 볼 수 있습니다.

## 데이터와 업그레이드

- Room v2 → v3는 `safety_followups` 테이블만 추가합니다. 연락처·설정·동작 기록·기존 문자 사건/수신자/본문을 보존합니다. v1 → v2 → v3 업그레이드도 지원합니다.
- 수동 확인 기록은 서버로 보내지 않고 앱의 백업 제외 저장소에 보관합니다. 90일이 지난 기록을 정기 작업에서 정리하고, 기록 삭제 시 함께 삭제합니다. 진행 중인 문자 중복 방지 상태는 유지합니다.
- 새 권한·광고·계정·네트워크·결제 SDK를 추가하지 않습니다. 앱 내 고지와 개인정보처리방침 원본을 함께 갱신합니다. 스토어 배포 전에는 갱신된 외부 방침도 배포되어야 합니다.

## 검증과 베타 체크리스트

- 서비스 상태 판정: 실행·시작·중단·오래된 heartbeat·미래 heartbeat·센서/권한/SIM 부족을 구분합니다.
- 데이터베이스: v1/v2 데이터 보존, 가족 기록의 중복 입력 방지·보존 기간·삭제, SMS 전송 상태와의 분리를 검증합니다.
- UI: 200% 글자 크기에서 간편 홈 스위치·점검 버튼·점검창 닫기가 조작 가능한지 검증합니다.
- SMS: 실제 활동 시각·원인 표시, 기록 없음 처리, 기존 재시도 메시지 스냅샷과 중복 방지 테스트를 유지합니다.
- 실기기에서는 업데이트 후 기존 연락처/12시간 설정 보존, 12시간 무활동·안부 자동 완료·SOS/시험 문자, 비행기 모드·재부팅·절전 상태를 다시 확인해야 합니다. 자동 테스트가 실제 통신사 SMS 성공을 보장하지는 않습니다.

## 이번 빌드에 포함하지 않는 기능

보호자 원격 모드, 서버 heartbeat/전원 꺼짐 감지, 보호자 응답 기반 단계별 에스컬레이션, 기관 대시보드와 구독 결제는 포함하지 않습니다. 현재 SMS 발송·전달 결과만으로 보호자가 읽거나 대응했다고 판단할 수 없습니다. 이 기능들은 계정·연결 동의·인증된 백엔드·푸시·구매 검증·삭제 흐름을 별도 구축하고 검증한 뒤 추가해야 합니다.
