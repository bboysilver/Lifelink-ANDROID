## 제공받은 기존 답변의 보완점

- 지인을 통해 모집하는 방식은 공식 권장 모집 방법에도 포함됩니다. 모집 경로 자체가 거절 이유라고 단정하지 않습니다.
- ‘설치해 두었다’는 설명에는 실제 기능 시험, 지속 사용, 실제 사용자와의 차이, 미참여자 확인이 빠져 있습니다. 추가 기간에는 본인별 실제 설치·시험 결과와 응답을 받습니다.
- ‘감지·문자·복구·UI를 개선했다’는 변경 설명은 코드 이력과 대조할 수 있으나, 어떤 의견/조건을 어떤 버전에서 재확인했는지 연결이 부족합니다. ‘알림 재시작’ 의견도 보고 버전/의미/확인 조건을 보완합니다.
- 기존343개는 과거2.3.9 자동 검사의 정확한 기록이고 현재2.3.10은357개입니다. 숫자가 과거였다는 이유만으로 거절됐다고 주장하지 않습니다. 자동 검사는 실제 SIM 수신·OEM절전·사용성/피드백의 대체 증거가 아닙니다.
- ‘최근 피드백 없음/문자는 오는 것 같다’는 사용자 보고는 보존하되 전원 참여·누락0·성공률100% 또는 준비 완료로 확대하지 않습니다.

## 공개를 보류할 조건

- 정상 사용 중 설명되지 않는 오발송, 실제 무활동 누락/중복, 조용한 중단·잘못된 정상 표시, 설정/연락처 손실이 미해결이면 보류.
- 최신 실제 기기 수신/절전·업데이트 시험 결과, 기존 신청 답변, 추가 기간의 피드백·재시험이 없으면 ‘준비 완료’라고 신청하지 않음.
- SMS·FGS·건강 앱·Data safety의 선언/심사 상태를 확인. Closed test 업데이트 승인과 모든 정책·Production access 승인은 별개.
- 사전 출시 보고서에 해당 버전의 결과가 없거나 온보딩/SIM 제한까지만 실행됐다면 핵심 SMS·백그라운드 시험 미검증으로 기록. edge-to-edge 권고는 현재 코드의 enableEdgeToEdge/Scaffold와 실제 대상 기기에서 대조하고 자동 안내만으로 무시/원인 확정하지 않음.
- 현재 로컬 앱은 전원OFF·강제 종료·통신 장애를 서버에서 보호자에게 통보하지 못함. 무료 보조 안전 도구라는 한계를 유지. Family/Care/결제는 이번 거절 해결 범위가 아님.
