# LifeLink 2.3.2 (40) 활동 감지 및 배지 회귀 검증

검증일: 2026-10-14. 실기기 장기 운영이나 공개 출시 승인을 의미하지 않습니다.

## 사용자 요청과 확인한 원인

- `[라이프링크 안전 알림]`은 설정 시간이 끝났을 때 보호자에게 보내는 핵심 무활동 경고입니다. 사용자 확인에 따라 이 기능은 유지하고 정상 활동을 놓쳐 발생할 수 있는 불필요한 발송을 줄입니다. 과거 특정 문자 한 건의 원인은 해당 기기의 활동/발송 기록 없이 확정할 수 없습니다.
- 기존 앱 화면 조작 기록에 30초 제한이 있어 10초 뒤 메뉴를 누르더라도 마감시각을 갱신하지 않았습니다. 같은 초의 연속 터치만 묶는 1초 제한으로 변경했습니다. 갱신 처리 시간 때문에 다음 입력이 불필요하게 다시 기록되지 않도록 제한 기준을 기록 완료 시점에 잡습니다.
- 시스템 잠금 해제 수신기를 앱 내부용 `RECEIVER_NOT_EXPORTED`로 등록했습니다. 제조사 System UI가 다른 UID를 사용하는 경우 누락될 여지가 있어 시스템 방송 수신용으로 수정했습니다. 필터는 시스템만 보낼 수 있는 보호된 `ACTION_USER_PRESENT` 하나만 허용하며 임의 외부 이벤트를 추가하지 않았습니다.
- 앱이 실제로 잠겨 있던 상태를 관측한 뒤, 잠금이 해제되고 화면이 켜진 상태로 다시 초점을 얻으면 방송 누락 시에도 활동을 갱신합니다. 단순 화면 점등/초점 변화는 활동으로 인정하지 않습니다.
- 실행 상태와 발송 완료 알림 채널이 배지를 허용하고 있어 정상 작동 중에도 알림 숫자가 남을 수 있었습니다. 배지를 표시하지 않는 무음 채널로 이동하고, 구 버전 발송 완료 알림만 정리합니다. 기존 중요 실패/사전 경고는 지우지 않습니다. 완료 알림은 누르면 닫힙니다.

## 보존한 기능과 개인정보

자동 걸음·반복 움직임 감지, 잠금 해제, 영속 마감시각, 무활동 사전 경고, 보호자 SMS, 실제 콜백, 중복 방지, 기존 재시도, SOS, 선택적 매일 안부 확인은 유지합니다. 새 로그인·서버·위치 추적·화면 내용 수집·앱 사용 내역·광고·결제 기능이나 권한은 추가하지 않습니다. 기존 알림 채널을 사용자가 차단했다면 새 무음 채널에도 차단을 유지합니다.

타이머는 활동이 확인될 때 설정 시간으로 갱신된 다음 다시 감소하는 것이 정상입니다. 앱을 켜 놓았다는 사실만으로 타이머를 멈추거나 사용자가 안전하다고 단정하지 않습니다. 사용자가 앱을 계속 열거나 수동 확인 버튼을 누를 필요는 없습니다.

- 10초 후 메뉴 조작, 1초 이내 입력 묶음, 잠금 해제 후 무터치 복귀, 잠긴 화면/비활성 화면/자동 초점 변경의 무시, 실행/완료 채널의 배지 해제, 기존 채널 차단 유지, 구 버전 완료 알림만 제거를 검사했습니다.
- 기존 무활동 마감·오래된 예약 작업 무시·유효 활동 후 사전 경고 취소·SMS 콜백 및 재시도 검사를 포함합니다.
- 첫 전체 검사에서 입력 처리 자체가 시간을 소비하는 경우의 묶음 처리 기준 문제가 드러나 이를 수정하고 최종 전체 검사를 다시 통과했습니다.
- 초기 서명 CI에서 실제 실행 시간에 의존하던 200ms 입력 간격 검사가 불안정하게 실패했습니다. 입력 간격 정책은 명시적 시간값으로 검사하고, 실제 Activity의 10초 후 메뉴 조작/잠금 복귀 검사는 그대로 유지하여 검증을 안정화했습니다. 초기 실패 빌드는 제출하지 않습니다.
- ADB 연결 기기 없음. 실제 삼성 잠금 해제 방송, 통신사 SMS, OEM 배지, 장기 절전은 이번 작업에서 검증하지 않았습니다.

## 실제 기기 확인

1. 기존 앱을 삭제하지 않고 2.3.2 (40)로 업데이트합니다. 보호자·SIM·12시간 설정이 유지되는지 확인합니다.
2. 앱 실행 → 화면 잠금 → 10초 이상 대기 → 잠금 해제 후 터치하지 않고 1~2초 내 마감시각/최근 활동이 갱신되는지 확인합니다.
3. 다른 앱을 사용하다가 돌아온 경우 최근 활동에 잠금 해제/움직임이 기록되는지 확인합니다. 다른 앱의 화면 내용을 읽거나 어떤 앱을 썼는지 추적하지 않습니다.
4. 앱에서 10초 대기 후 메뉴 이동 시 설정 시간으로 갱신되는지 확인합니다. 이후 매초 감소하는 것은 정상입니다.
5. 필요한 오류가 없는 정상 상태에서 실행 알림 때문에 배지가 생기지 않는지 확인합니다. 사전 경고·중단·실패 같은 확인 필요한 알림의 배지는 남을 수 있으며, 제조사 런처 설정도 영향을 줍니다.
6. 동의한 보호자와 무활동 경고·SOS·실패 재시도를 확인합니다. 과거 불필요한 문자 조사에는 앱 버전과 발송 기록의 마지막 활동 시각/사유/마감시각이 필요합니다. 번호나 문자 내용을 공개할 필요는 없습니다.
